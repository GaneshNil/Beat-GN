# Audit change log

| Original issue | Source | Resolution | Verification evidence |
| --- | --- | --- | --- |
| Late or unrelated callbacks could complete a queued request, and a queued request could start on a closed link | `MarvNeoBleManager.kt`, `GattOperations.kt` | Use one looper, capture the GATT link before queueing, match callback IDs and retire ambiguous sessions on timeout/cancellation. Route DIS reads by UUID. | `GattOperationsTest`; API 30–32 and API 33+ paths compiled. |
| Scan and reconnect lifecycle could interfere with a current session or undo a deliberate disconnect | `MarvNeoBleManager.kt`, `ReconnectBackoff.kt`, `WatchScreen.kt` | Per-scan callbacks, manual selection, support for unnamed advertisements, cancel/disconnect options during setup, explicit disconnect preference and bounded retries. | Backoff test, source trace, physical checklist. |
| Foreground link depends on permissions and Bluetooth broadcasts | `MainActivity.kt`, `WatchCompanionService.kt`, `AndroidManifest.xml` | Recheck permissions, expose recovery from Watch, handle foreground rejection and close link on teardown. Receive the protected Bluetooth state action. | Manifest and Android lint checks. |
| Protocol parser accepted an unknown version and all writes used the default version | `CrrepaProtocol.kt`, `MarvNeoBleManager.kt` | Reject invalid versions in direct parsing, select the wire version according to the documented ATT chunk calculation. | `CrrepaProtocolTest` with a reproduced red test and MTU version test. |
| Fast responses and disconnection could strand measurement controls | `MeasurementRequest.kt`, `MarvNeoBleManager.kt`, `HealthScreen.kt`, `HomeScreen.kt` | Process-scoped requests, preserve early results, suppress repeated starts, verify pulse notify availability and show timeout instead of unsupported for BP silence. | `MeasurementRequestTest`, parsers, manual watch cases. |
| Incomplete activity values were rendered inaccurately and same-step changes were lost | `MarvNeoBleManager.kt`, `HealthRepository.kt`, `HomeScreen.kt` | Preserve reported zero, distinguish missing distance/calories/active minutes, save complete tuples, dedupe against the last snapshot per local day. | Protocol and repository tests. |
| Concurrent writes and interleaved readings inflated counts. Zone and midnight changes could invalidate a report. | `HealthRepository.kt`, `HealthAggregator.kt`, `HealthScreen.kt` | Serialize duplicate-check and insert, bound dedupe to calendar day, recompute in the current zone, refresh active reports and filter inactive period results. | Failing concurrent copy reproduction, fixed repository and aggregation tests. |
| Alarm editor silently corrected bad values, and watch writes could be affected by competing edits or navigation | `AlarmRepository.kt`, `AlarmSlots.kt`, `WatchScreen.kt`, `HealthEntities.kt` | Validate, allocate at save, serialize save/send/delete, keep unsent and transport-sent states distinct, require confirmation for local deletion. | `AlarmSlotsTest`, repository tests, migration defaults tests, device checklist. |
| Legacy assistant entries, chart labels, form controls and report copy could mislead | `AssistantScreen.kt`, `MainActivity.kt`, `Metrics.kt`, `HealthScreen.kt`, `WatchScreen.kt` | Label migrated rows, confirm history deletion, restore navigation/editor values, wrap measure controls, add scrollable chart dates and TalkBack descriptions, and describe local history accurately. | Chart label unit tests and lint; render and accessibility checks blocked. |
| Raw protocol data and address data could be disclosed; device transfer could copy storage | `MarvNeoBleManager.kt`, `WatchScreen.kt`, `MoreScreen.kt`, manifest and `data_extraction_rules.xml` | Retain metadata-only diagnostics and address suffixes. Exclude database and preferences from cloud backup and Android device transfer. | Source and merged manifest review. |
| Room singleton initialization could create two instances and device migration had no test harness | `AppDatabase.kt`, `RoomMigrationTest.kt` | Recheck inside the lock and add an Android v1 fixture that uses real Room migration and reopens a saved alarm. | Six SQLite JVM tests; Android test APK compilation; execution blocked. |
| AGP was below the supported SDK 35 version and SQLite JDBC bundled older fixes | `gradle/libs.versions.toml`, `app/build.gradle.kts`, `.github/workflows/build-apk.yml` | Update AGP to 8.6.1 and test-only SQLite JDBC. Add lifecycle-aware Compose collection and AndroidX test runner. CI compiles instrumentation APK. | Clean local Kotlin, Gradle, lint, APK and JVM test run. CI was reviewed locally. |
