# Feature verification matrix

`VERIFIED_BY_TEST` refers to an exercised automated code path. `BLOCKED` refers to a scenario that requires an unavailable device, emulator or firmware capture. There are zero `VERIFIED_ON_DEVICE` results in this pass. See [Test results](TEST_RESULTS.md) and the [V006213 report](MARV_NEO_V006213_COMPATIBILITY.md).
